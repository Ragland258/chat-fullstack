# Chat 完整源代码（UI 改版）

本目录可以直接作为 Qt Creator/CMake 项目打开。

## 保持不变

- HTTP 请求接口、信号槽、请求字段、枚举和业务流程保持原项目内容。
- `httpmgr.cpp/.h`、`const.h`、`singleton.h`、聊天窗口相关文件未做 UI 需求以外的改动。

## UI 调整

- 登录页为接近 QQ 登录器的小尺寸窗口。
- 登录页显示头像；不显示自动登录和扫码登录。
- 原扫码入口位置改为“忘记密码”。
- 注册页不显示头像，左上角只显示 `<` 返回，右上角只显示关闭按钮。
- 图片通过 `resources.qrc` 的 Qt 资源路径加载，不包含任何本机绝对路径。

## 首次构建

若曾出现磁盘路径被错误拼接的构建报错，请先关闭 Qt Creator 并删除旧 `build` 目录，然后重新运行 CMake。
